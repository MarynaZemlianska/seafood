# Seafood from Norway

Одностраничный сайт о норвежских морепродуктах: каталог продукции, рецепты, история, форма для оптовиков.

## Возможности

- Адаптивная вёрстка (десктоп, планшет, телефон)
- Карусель продукции на 10 видов (Slick)
- Модальные окна заказа и рецептов (fancyBox)
- Языки: украинский (основной) и английский
- Анимация первого экрана и появление элементов при прокрутке
- Учитывается системная настройка «Уменьшить движение»

## Запуск

Сборка не нужна — достаточно открыть `seafood_site/index.html` в браузере.

## Деплой (Netlify)

Настройки лежат в `netlify.toml`: публикуется папка `seafood_site`, сборка не нужна. В Netlify в качестве production-ветки должна быть выбрана `main`.

## Структура

```
seafood_site/
├── index.html
├── css/
│   ├── style.css            # основные стили, адаптив, анимации
│   ├── reset.css
│   ├── slick.css
│   └── jquery.fancybox.css
├── js/
│   ├── main.js              # слайдеры, меню, формы, переключение языка
│   ├── reveal.js            # анимация появления при прокрутке
│   ├── i18n.js              # английские переводы
│   ├── slick.min.js
│   └── jquery.fancybox.min.js
└── images/
    └── products/            # иллюстрации продукции (SVG)
```

## Настройка

- **Отправка форм.** Укажите адрес обработчика в `FORM_ENDPOINT` в начале `js/main.js`. Пока он пустой, заявки никуда не отправляются — пользователь видит только сообщение об успехе.
- **Соцсети.** Ссылки на Instagram, Telegram и Facebook в подвале `index.html` ведут на главные страницы сервисов — замените их на свои аккаунты.
